# 技术栈

GoWherer 采用现代化前端与跨平台技术组合，兼顾开发效率、性能与可维护性。

## 应用层
- Expo SDK 55
- React Native 0.83.6
- React 19.2.0
- TypeScript
- expo-router（文件路由）

## 地图与定位
- expo-gaode-map（高德地图 SDK 封装）
- react-native-maps（地图组件）
- expo-task-manager（后台任务管理）

## 文档与站点
- VitePress
- Vue 3
- Markdown

## 工程化
- ESLint（代码规范）
- npm scripts（任务管理）
- EAS Build（云构建）

## 设计原则
- 跨平台优先：同一套业务逻辑覆盖移动端与 Web。
- 本地优先：核心数据以本地可用为前提。
- 可维护性优先：模块化组织与清晰边界。
- 体验优先：关注加载速度与交互流畅度。

features:
    - title: 快速记录
      details: 开始旅程后，一键记录文字、位置、照片、视频和音频，让每个瞬间都不会被遗漏。
    - title: 模板记录
      details: 内置"出发"、"到达"、"休息"、"打卡"模板，一键录入预设文本与标签，支持旅行与通勤双模式。
    - title: 交通费记录
      details: 为每条记录标记交通方式与花费，自动汇总旅程总费用，导出时生成交通费明细表。
    - title: 回顾与详情
      details: 旅程回顾页以摘要列表快速浏览，点开进入详情页重温时间线、媒体与轨迹地图。
    - title: 统计与分段
      details: 自动统计总里程、总时长、平均速度与定位点数，还可任选起止记录点查看分段里程、耗时与均速。
    - title: 路线可视化
      details: 后台持续记录 GPS 轨迹，轨迹平滑去噪；小地图预览可原地放大交互，分段区间高亮显示。
    - title: 导出与分享
      details: 一键导出 PDF 或长图，内置"经典"与"简约"两套导出模板，含轨迹图、统计与交通费明细。
    - title: 智能定位
      details: 自动获取位置信息，通过高德逆地理编码转换为可读地点名称，并带本地缓存与请求去重，省流量更迅速。
    - title: 数据安全
      details: 数据一键备份与导入恢复；删除旅程时级联清理媒体文件，设置页支持孤儿文件扫描与存储清理。

GoWherer is free, open source, and ad-free. Android installers are currently distributed through the following channels.

Scan the QR code or open the link to download and install the latest version:

## GitHub Releases

Find all previous versions, release notes, and build artifacts (APK / AAB):

- Link: <https://github.com/dsjerry/gowherer/releases>

## Installation Notes

- System requirement: Android 7.0 (API 24) or above.
- Allow "install unknown apps" when prompted for first-time installation.
- Amap-powered features (place picker, track map) are built into the installer — no extra configuration needed.

## Release Notes

Release notes are published with every GitHub Release. See the [Releases page](https://github.com/dsjerry/gowherer/releases) for details.

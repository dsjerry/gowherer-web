# 关于与反馈

GoWherer 是一款开源的旅程时间线应用：出发、记录、回顾，把每一次出行变成可分享的时间线。它由 [@dsjerry](https://github.com/dsjerry) 使用 Expo / React Native 开发，以 [MIT 许可证](https://github.com/dsjerry/gowherer/blob/main/LICENSE)开源。

## 为什么做这个

旅行和通勤中会产生大量片段——照片、位置、花费，散落在相册和聊天记录里，事后很难拼回一次完整的出行。GoWherer 把这些片段收进一条按时间排列的旅程线：行程进行中随手记，结束时自动算清里程与花费，需要时一键导出 PDF 或长图分享。

所有数据仅保存在你自己的设备上，没有账号，没有云端，也没有广告。

## 开源许可

项目基于 MIT 许可证开源。应用内"设置 → 开源许可"页面列出了全部依赖及其许可信息，支持按许可类型筛选与搜索。
